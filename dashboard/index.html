monitor_heart 1. Intensitäts-Profil

Zeigt die Intensitätsverteilung der erkannten Zellen — so siehst Du, wo schwache Zellen fälschlich gezählt oder helle übersehen werden.

science 2. Parameter-Optimierung

Du gibst die erwartete Zellzahl pro Bild ein — das System testet Parameter-Kombinationen und findet die beste Balance (F1 + MAE).

Hinweis: cpsam nutzt nur die ersten 3 Kanäle (truncated). Bei 4 Kanälen (PomC/DREADD/Fos/Gal) den 4. weglassen oder mit einem Zytoplasma-Kanal kombinieren.

school 3. Eigenes Modell trainieren (Fine-Tuning)

Die beste Lösung für dauerhaft schwierige Bilder: Mit annotierten Bildern (bild_masks.tif) ein eigenes Cellpose-Modell trainieren. Doku: cellpose.readthedocs.io

API

Direktzugriff auf das Backend

Endpoints

  • GET /health
  • GET /version
  • POST /jobs/upload
  • GET /jobs/{id}
  • GET /jobs/{id}/download?file=...

Beispiel Upload

curl -X POST http://localhost:8001/jobs/upload \
  -F "files=@sample.czi" \
  -F "channels=0,1,2,3" \
  -F "model_name=cyto2" \
  -F "use_gpu=true" \
  -F "channel_names=PomC,DREADD,Fos,Gal"
