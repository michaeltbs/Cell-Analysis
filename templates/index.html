How Calibration Works

  1. Select 3-4 representative images from your input folder (1 per group/region recommended)
  2. Enter the expected cell count for each image (manually counted)
  3. Click "Start Calibration" - the system tests all 15 sensitivity levels
  4. Review results and apply the recommended level to Detection tab

  2. Select 3-4 samples with known co-expression cell counts
  3. Choose which channel pair to calibrate (e.g., Ch0 + Ch1)
  4. System tests 9 parameter combinations and finds optimal settings
